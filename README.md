# Proyectos de IoT

Repositorio personal de proyectos, ejercicios y talleres desarrollados para la materia de **Internet de las Cosas (IoT)** en la universidad.

Aquí se irán agregando nuevas carpetas con el código, la documentación y las evidencias de cada actividad realizada durante el semestre.

## Proyectos

- [`taller_2_iot/`](taller_2_iot/): sistema IoT conectado a Azure IoT Central, con dispositivos simulados, una VM con Python y un ESP32 simulado con Wokwi.

Cada proyecto tendrá su propio README con la explicación de la actividad, las tecnologías utilizadas, el estado y las instrucciones necesarias para ejecutarlo.
